# Fabric Medallion Architecture Playbook

## 1. Architectural Principles
- **Bronze (Raw / Landing)**:
  - Exact 1-to-1 copy of source data.
  - Store as Delta format with metadata columns (`_ingested_at`, `_source_file`).
  - No data type casting or filtering.
- **Silver (Conformed / Curated)**:
  - Deduplicated on Primary Keys using Delta Lake `MERGE`.
  - Timestamps normalized to ISO 8601 UTC (`yyyy-MM-dd HH:mm:ss`).
  - Null handling and type validations applied.
- **Gold (Aggregated / Business)**:
  - Dimensional models (Fact & Dimension tables).
  - Pre-aggregated metrics for Power BI Direct Lake mode.

## 2. Dynamic Lakehouse Naming Convention
- Naming format: `lh_<domain>_<layer>` (e.g. `lh_sales_bronze`, `lh_sales_silver`, `lh_sales_gold`).
- Lakehouse item creation payload:
  ```json
  {
    "displayName": "lh_<domain>_bronze",
    "type": "Lakehouse",
    "description": "Bronze landing lakehouse generated by Fabric AI Studio"
  }
  ```

## 3. PySpark Notebook Template
Every generated notebook must use the `synapse_pyspark` kernel and standard OneLake ABFSS paths:

workspace_id = spark.conf.get("trident.workspace.id")
